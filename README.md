# Digital Clocks
 
A simple digital clock built with Python
 
## How to Run
 
```bash
python digital_clock.py
```
 
## Features
 
- Displays current time in `HH:MM:SS AM/PM` format
- Shows full weekday and date below the clock
- Auto-updates every second
- Dark theme with green terminal-style text
- Centered window, fixed size
